# P1_DataRepositories_269570239

The data used within the study titled "A comparative study of the structural optimisation approaches for printable
lattice structures" were obtained from the prior works:
https://doi.org/10.1016/j.addma.2022.103238 (TO+ML approach), 
https://doi.org/10.1007/s00158-024-03880-1 (dehomogenisation),
https://doi.org/10.1007/s00158-015-1294-0 (inverse homogenisation) and 
https://doi.org//10.1007/s00158-010-0594-7 (high resolution TO). 

The other data for reproduction is stored in this folder as below:
- Pixel data of final structure (*.mat file for each approach, four in total)
- Training dataset for ML in 2step optimisation (*.mat file for R, Vf and D)
